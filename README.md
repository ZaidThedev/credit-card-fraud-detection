# Credit Card Fraud Detection

Predicting fraudulent transactions from 594,643 card payments (1.2% fraud).

- **Notebook:** `fraud_detection.ipynb`
- **Presentation:** `presentation/Credit Card Fraud Detection.pptx`

**Final model:** tuned XGBoost, PR-AUC 0.930. It catches 92% of fraud (1,324 of 1,440 in the test set).

## How to run
Unzip `data/interview case study.zip`, run `pip install -r requirements.txt`, then run all cells in the notebook.
